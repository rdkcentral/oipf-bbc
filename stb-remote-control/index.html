📺 RDK STB Remote Control

Applications

Enter the STB host and click “Connect”.

Data from org.rdk.AppManager.getInstalledApps + getLoadedApps and .listPackages (bolt package version). Actions call launchApp, closeApp, terminateApp, killApp, org.rdk.RDKWindowManager.setFocus and .uninstall. Pick the package plugin from the dropdown in the top right.

Remote Control

Keys are injected to the app that currently has focus (injectKey is global). Set focus first, then press buttons on the remote.
